JR Delipack ModelKit

Photo-assisted rotational modelling. This is manual reference tracing, not automatic photo reconstruction.

Project background: JR DELIPACK

1. Reference and material half-section

Use a side-on reference or a simple section drawing. A photo does not reveal hidden inner walls. Supply or draw those explicitly; do not infer precision from pixels.

Load a reference. Set two axis points, then trace a CLOSED material boundary.

Trace outside bottom → outside wall → rim → inside wall → inside floor → axis, then export. Closure is automatic. Use both inner and outer paths, not just a silhouette. R is radius, not diameter. More complex wall offsets, snap fit and photographic calibration are not validated here.

Keyboard-accessible numeric alternative

The Python recipe accepts explicit [radius_mm, height_mm] points or a tapered-bowl preset. Canvas clicking is optional. See docs/INPUT_FORMAT.md and examples/demo_set.json.

2. Inspect generated mesh

Run the local Python build, then load its mesh.json. Drag to orbit; use the zoom slider. This viewer is not a fit, material or capacity test.

Choose generated mesh.json. No models are fetched from the production website.
