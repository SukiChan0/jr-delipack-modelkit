# Contributing

Start with a narrowly reproducible issue, supported input and expected behaviour. Never attach customer photos or unlicensed models. Clearly label synthetic examples and estimates.

Run `python -m unittest discover -s tests -v` and inspect both exported part names and units. Browser and Blender changes require actual runtime evidence from the corresponding environment; syntax checks are insufficient.

Contributions must be rights-cleared and offered under the applicable project license. Retain dependency and asset attribution. Human review is required before accepting untrusted code or making a public release.

Keep geometry, source-status metadata, CLI safety and frontend contracts separate. Do not add cloud inference, telemetry, pricing, mandatory backlinks, blanket credential access or runtime package installation as a surprise dependency.

A small fix is better than a second model pipeline, large game engine or new generic editor. Production JR DELIPACK systems are not this repository's test targets.
